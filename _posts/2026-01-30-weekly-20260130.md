#### 1. [Pangolin (YC S25) is hiring software engineers (open-source, Go, networking)](https://docs.pangolin.net/careers/join-us)
**출처:** hackernews | **날짜:** 2026-01-30

Pangolin은 YC S25 출신 스타트업으로, 레거시 VPN을 대체하는 identity-aware 원격 접근 플랫폼을 구축하고 있습니다. 오픈소스이며 셀프호스팅을 기본으로 지원해 팀이 데이터와 인프라에 대한 통제권을 유지할 수 있고, 정책 기반 접근 제어와 표준 IdP 통합, 관측성과 API 자동화를 갖춘 점이 특징입니다.

**핵심 포인트:**
- VPN 대체 솔루션의 핵심은 identity-aware 접근 제어로, 네트워크 레벨이 아닌 사용자/정책 기반으로 접근을 관리하는 제로 트러스트 접근 방식을 채택합니다.
- 오픈소스 + 셀프호스팅 모델은 데이터 주권이 중요한 조직에 적합하며, 소스 코드를 직접 감사하고 커스터마이징할 수 있는 장점이 있습니다.
- Go 기반의 네트워킹 인프라 소프트웨어 개발에 관심 있는 개발자에게 실제 프로덕션급 오픈소스 프로젝트에 기여할 수 있는 기회입니다.

#### 2. [Show HN: Cicada – a scripting language that integrates with C](https://github.com/heltilda/cicada)
**출처:** hackernews | **날짜:** 2026-01-30

Cicada는 C 코드 내부에서 직접 실행되는 경량 스크립팅 언어입니다. 헤더 파일 하나를 포함하고 링커 옵션만 추가하면 C 프로그램에 스크립팅 기능을 임베딩할 수 있어, Lua나 Python 임베딩보다 더 가볍고 직관적인 통합이 가능합니다.

**핵심 포인트:**
- C 프로그램에 스크립팅을 임베딩해야 할 때 `#include`와 `-lcicada` 링커 옵션만으로 통합할 수 있어, 빌드 복잡도를 최소화할 수 있습니다.
- IoT, 임베디드 시스템, 게임 엔진 등 C 기반 프로젝트에서 런타임 설정이나 사용자 정의 로직이 필요할 때 경량 스크립팅 레이어로 활용할 수 있습니다.
- Lua, Tcl 같은 기존 임베디드 스크립팅 언어와 비교할 때, 의존성이 최소화되고 C와의 데이터 교환이 직접적이라는 점이 차별화 포인트입니다.

#### 3. [Track Your Routine – Open-source app for task management](https://github.com/MSF01/TYR)
**출처:** hackernews | **날짜:** 2026-01-30

TYR(Track Your Routine)은 Flutter 기반의 크로스플랫폼 일과 관리 앱으로, Firebase Auth와 Firestore를 백엔드로 사용하며 로컬 알림 기능을 제공합니다. Android, iOS, Web, Windows, Linux, macOS를 모두 지원하는 오픈소스 프로젝트로, Flutter + Firebase 스택을 학습하거나 사이드 프로젝트의 참고 코드로 활용하기 좋습니다.

**핵심 포인트:**
- Flutter + Firebase 조합으로 하나의 코드베이스에서 6개 플랫폼(Android, iOS, Web, Windows, Linux, macOS)을 지원하는 실제 사례를 참고할 수 있습니다.
- Firebase Auth, Cloud Firestore, 로컬 알림 등 모바일 앱 개발에 자주 쓰이는 패턴이 구현되어 있어, Flutter 입문자에게 좋은 학습 자료입니다.
- MIT 라이선스 오픈소스이므로, 자신의 프로젝트에 코드를 참고하거나 기여를 통해 오픈소스 경험을 쌓을 수 있습니다.

### 📚 This Week's Picks

#### 1. [Pangolin (YC S25) is hiring software engineers (open-source, Go, networking)](https://docs.pangolin.net/careers/join-us)
**Source:** hackernews | **Date:** 2026-01-30

Pangolin, a YC S25 startup, is building an identity-aware remote access platform to replace legacy VPNs. #### 2. [Show HN: Cicada – a scripting language that integrates with C](https://github.com/heltilda/cicada)
**Source:** hackernews | **Date:** 2026-01-30

Cicada is a lightweight scripting language that runs directly inside C code. By including a single header file and adding a linker option, you can embed scripting capabilities into any C program — offering a simpler and more lightweight integration than embedding Lua or Python.

**Key Points:**
- Integrating scripting into C programs requires only `#include` and a `-lcicada` linker flag, minimizing build complexity.
- Useful as a lightweight scripting layer for runtime configuration or user-defined logic in IoT, embedded systems, or game engines built on C.
- Compared to established embedded scripting languages like Lua or Tcl, Cicada stands out with minimal dependencies and direct C data exchange.

#### 3. [Track Your Routine – Open-source app for task management](https://github.com/MSF01/TYR)
**Source:** hackernews | **Date:** 2026-01-30

TYR (Track Your Routine) is a cross-platform routine management app built with Flutter, using Firebase Auth and Firestore as its backend with local notification support.
