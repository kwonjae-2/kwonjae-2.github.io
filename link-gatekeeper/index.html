나쁜 주소를 쫓지 않고, 진짜 주소를 기억합니다.

사칭 주소 가람은행을 내세웠지만 공식 주소와 다릅니다. 진짜 앱으로 안내합니다.

  1. 평소처럼 누릅니다

    문자, 메일 어디서든 링크를 누르면 Link Gatekeeper가 먼저 받습니다.

  2. 주소를 끝까지 확인합니다

    단축 주소를 풀어 최종 도착지를 찾고, 기기 안에서 공식 목록과 대조합니다.

  3. 공식이면 통과, 사칭이면 안내

    공식 주소는 아무 화면 없이 열립니다. 사칭이면 진짜 앱을 여는 버튼을 드립니다.

기존 확인 서비스

  • 의심이 들 때 직접 복사해서 확인
  • 악성, 주의, 정상 중 하나로 판정
  • 그다음 어디로 가야 하는지는 스스로 찾기

Link Gatekeeper

  • 누르는 순간 자동으로 확인
  • "가람은행 주소가 아닙니다"처럼 누구를 사칭했는지 설명
  • 진짜 공식 앱과 해당 메뉴를 바로 열기

데모 다시 보기

Link Gatekeeper는 가칭이며, 이 페이지는 서비스 구상을 설명하기 위한 샘플입니다. 가람은행을 비롯한 화면 속 기관은 실재하지 않는 가상의 이름이고, 주소와 알림은 모두 예시입니다.
